Использованные команды:
git status 
• Выводит сводку по:
• текущей ветке;
• измененным файлам, которые еще не подготовлены к коммиту (unstaged);
• файлам, добавленным в область подготовки (staged через git add), которые войдут в следующий коммит;
• новым неотслеживаемым файлам (untracked).
git diff
• Что делает: Сравнивает рабочую директорию (файлы на вашем компьютере) с индексом (staging area).
• Что именно показывает: Неиндексированные изменения — то есть разницу между тем, что вы сохранили в буфер через git add в последний раз (или последним коммитом, если add не вызывался), и тем, как файл выглядит прямо сейчас в редакторе.
• Зачем нужно: Чтобы проверить свои правки перед тем, как добавлять их в индекс (git add).
git diff --staged (или git diff --cached)
• Что делает: Сравнивает проиндексированные изменения с последним коммитом (HEAD).
• Что именно показывает: Разницу между последним коммитом и тем состоянием файлов, которое вы уже подготовили к следующему коммиту с помощью команды git add.
• Зачем нужно: Чтобы еще раз внимательно перепроверить готовый к фиксации код перед выполнением git commit.
Ветки:
git switch -c explain-branches - переключились на новую ветку
