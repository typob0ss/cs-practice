 git log — это хронологическая история проекта. Команда выводит список коммитов, их авторов, даты и сообщения. Она отвечает на вопрос: «Что и когда происходило в репозитории?». Сам по себе log не показывает изменения внутри файлов.
 git show — это детали конкретного коммита. Команда берет один объект (по умолчанию — последний коммит) и разворачивает его содержимое. Она отвечает на вопрос: «Что именно изменилось в этом конкретном шаге?». Вы увидите автора, сообщение и весь добавленный/удаленный код.
 git diff — это динамическое сравнение состояний. Команда показывает разницу между двумя точками (например, между вашим текущим неотредактированным кодом и последним сохраненным коммитом). Она отвечает на вопрос: «Что изменилось между состоянием А и состоянием Б прямо сейчас?».
  git log -S "текст" — ищет изменение количества упоминаний строки во всей истории. Git прочесывает все коммиты и выводит только те, где указанное слово или кусок кода появились или исчезли. Это лучший способ найти коммит, в котором когда-то давно добавили или удалили определенную функцию.
 git blame — ищет автора последней правки для каждой строки файла. Команда построчно выводит файл и напротив каждой строчки пишет: хэш коммита, имя автора и дату, когда эта строка была изменена в последний раз. Используется, чтобы понять, к кому идти с вопросами по конкретному участку кода.
